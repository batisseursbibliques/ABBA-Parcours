📲 Install ABBA Parcours

Pour écouter les leçons et la Bible même écran éteint ou quand vous quittez l'application. Pour téléphones Android.

To listen to the lessons and the Bible even with the screen off or when you leave the app. For Android phones.

⬇️ Télécharger l'application⬇️ Download the app

Fichier ABBA-Parcours.apk · environ 4,5 MoFile ABBA-Parcours.apk · about 4.5 MB

  1. Touchez « Télécharger l'application » ci-dessus et attendez la fin du téléchargement.
  2. Ouvrez le fichier ABBA-Parcours.apk (touchez la notification de téléchargement, ou ouvrez-le dans « Fichiers » → « Téléchargements »).
  3. Si Android le demande, autorisez l'installation depuis cette source, puis touchez Installer. Si une alerte de sécurité (Play Protect) apparaît, touchez Installer quand même : l'application vient de l'équipe ABBA.
  4. Ouvrez « ABBA Parcours », connectez-vous avec votre compte habituel et acceptez les notifications.
  5. Pour que la lecture ne s'arrête jamais écran éteint : onglet Bible → ⚙️ → 🔋, puis autorisez l'application à ne pas être limitée par la batterie.
  1. Tap “Download the app” above and wait for the download to finish.
  2. Open the file ABBA-Parcours.apk (tap the download notification, or open it in “Files” → “Downloads”).
  3. If Android asks, allow installation from this source, then tap Install. If a security warning (Play Protect) appears, tap Install anyway: the app comes from the ABBA team.
  4. Open “ABBA Parcours”, sign in with your usual account and allow notifications.
  5. So that reading never stops with the screen off: Bible tab → ⚙️ → 🔋, then allow the app not to be limited by battery saving.
iPhone ? Cette application ne s'installe que sur Android. Sur iPhone, continuez dans le navigateur : la lecture reprendra où elle s'est arrêtée quand vous reviendrez dans l'application.
